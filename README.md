# Chocciee's Thumbnail Maker
This is a Thumbnail maker with templates for GW2 because my friend Barti is too unc to make thumbnails himself :>

### User instrction
Access the tool here: https://chocciee.github.io/thumbnail-maker-for-the-uncs/

### Available Features
- Auto set to default Youtube Thumbnail size
- Allow Image or Plain colour background
- Add vignette and/or fade to background
- Add image from system image bank (managed by me and useable by everyone)
- Add image into the maker from your local (can only be seen and used by you, sits in your browser)
- Add text boxes, change font size, width, opacity, outlines and orientation
- Remove image background (poorly)
